Fix first

1. Any logged-in user can read any other user's notes. The notes table has RLS turned off. Add a policy limited to auth.uid() = user_id; SQL included.

2. The service role key is used in a browser-callable function. api/admin/route.ts:18 uses the service role key and skips your row-level rules. Move this to a server-only path and check the signed-in user first.

3. Uploaded files are not isolated by customer. The Storage bucket policy allows any authenticated user to read any object. Limit reads to that user's folder.

Fix soon

4. A public API route returns records by id with no auth check (api/docs/[id]/route.ts:12). Require a session and confirm the record belongs to that customer.

Lower risk

5. Signup allows disposable email domains. Low risk for a private pilot; tighten later if you open signups.
